# Nexus UI - Premium Directory & Showcase Kit

A sleek, ultra-responsive directory and component showcase kit built with **Tailwind CSS**, **Vanilla JavaScript**, and modern **Glassmorphism** styling. Perfect for developers, freelancers, and agencies looking to bootstrap portfolios, tool directories, or client dashboards.

## 🚀 Features
* **Zero Dependencies (Aside from Tailwind CDN):** Lightweight and blazing fast.
* **Instant Client-Side Search:** Real-time keyword filtering across titles, descriptions, and tags.
* **Category Pill Filtering:** Smooth transitions between UI components, scripts, and templates.
* **Interactive Modals:** Detailed view pop-ups for individual assets.
* **Dark Mode Native:** Beautiful slate-950 aesthetic optimized for modern eyes.

## 📂 File Structure
* `index.html` - Main markup and Tailwind configuration.
* `style.css` - Custom scrollbars and glassmorphism styling layers.
* `script.js` - Data array, search/filter logic, and modal rendering engine.

## ⚙️ Quick Customization
1. Open `script.js`.
2. Edit the `items` array to add, remove, or modify your own components, tools, or templates.
3. Deploy instantly to Vercel, Netlify, or GitHub Pages.
